# 提示词模板（可直接粘）

> 两段分开用，中间别偷懒：**抽取的 prompt 里不许出现"总结/归纳/提炼"**，**组装的 prompt 里不许出现转录原文**。

---

## 一、抽取（逐块跑，输入 = 一块转录）

把 `{{TERMS}}`、`{{BLOCK}}`、`{{SLOT}}` 换掉再发。

```
你在做一份会议录音的「事实抽取」，不是写总结。

【术语表（锁定，不许改写）】
{{TERMS}}

【本块原文】行号从 {{SLOT}} 开始
{{BLOCK}}

规则：
1. 你唯一要做的事：把原文里的事实原样抠出来，标上行号。
2. 严禁总结、归纳、提炼、美化、补全。原文没说的，一个字都不许加。
3. 先输出 <quotes>：逐字复制原文句子（可截断，不许改字），每条前面标行号。
4. 再输出 <facts>：只基于上面的 quotes 写，格式见下。
5. 行号只是数字，不许编。找不到行的东西，放进 <pending>。
6. 归属判不准（分不清谁是客户谁是我方）→ speaker 写"存疑"，并在 pending 里说明。
7. 听不清的字 → 原样保留并标〔听不清〕，不许猜。

<quotes>
L12: （原文逐字）
L15-17: （原文逐字）
</quotes>

<facts>
- statement: 一句话事实（不许有判断词）
  group: A量 / B原话 / C顾虑 / D功能点 / E时间线 / F不确定
  speaker: 客户 / 我方 / 第三方 / 存疑
  quote: 逐字原文
  lineNo: L12 或 L15-17
  confidence: 确定 / 存疑
</facts>

<pending>
- 没能归档的、听不清的、前后矛盾的
</pending>
```

**六个组各抽一遍**（A 量／B 原话／C 顾虑／D 功能点／E 时间线／F 不确定），比自己定"重要不重要"稳定得多。

---

## 二、组装（输入 = 素材稿，**不给原文**）

```
你是会议纪要的执笔，只依据下面这份素材稿写作。

【不许做的事】
- 素材稿里没有的事实，一个都不许写。你没有原文，也不许猜原文。
- 不许把"可以考虑""回头再说""先这样"写成"决定/确定/已定"。
- 不许补时间、地点、参会人、部门岗位。
- 不许出现内部判断、待核事项、客户评价。

【分章规则】
- 现状、问题：每一句都必须能在素材稿里找到对应条目（写的时候在心里对行号）。
- 我方答复/方案：只许用素材稿里 speaker=我方 的条目，而且必须是现场讲过的。
- 费用：数字必须是素材稿里的原数，不许"约""左右"。
- 下一步：只写两行；时间未定的写"待定"，不许编日期。

【待办】
每条必须是"谁 + 做什么 + 何时"三要素齐全；缺哪个就标出来，不许补。

【素材稿】
{{MATERIAL}}
```

---

## 三、自查（出稿前后各跑一遍）

```
拿你刚写的每一段，回答三个问题：
1. 这一段对应素材稿的哪几条？（给行号）
2. 里面有没有素材稿没有的词——尤其是数字、日期、功能名、承诺？
3. 有没有把客户的条件限定词吃掉了（"预算允许下""先看第一期"）？
答不出来的段落，重写。
```

---

## 四、别用的提示词形状

| 别这么写 | 为什么 |
|---|---|
| "把这份 6 万字录音总结成会议纪要" | 直接长上下文，实测正确率大幅下降；且它必须编，因为填不满结构 |
| "先通读全文，再提炼要点" | 通读=跳读，后半段被顺掉 |
| "你是一个资深咨询顾问，请输出专业的…" | 角色扮演不解决事实问题，只会加"专业废话" |
| "如果有不确定的可以合理推测" | 这句话在纪要场景等于允许编造 |
